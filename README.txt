LANDING PAGE - ALBERT FLORES

Archivos:
- index.html: estructura y contenido de la landing page.
- styles.css: estilos, diseño responsive y distribución.
- assets/: imágenes recortadas de las capturas de referencia.

Para visualizar:
1. Descomprime el archivo.
2. Abre index.html en tu navegador.
3. Para editar, modifica index.html y styles.css.

La tipografía se carga desde Google Fonts; si no hay conexión, se usan fuentes de respaldo.
